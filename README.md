# Гант-плани проєктів

Кожен проєкт лежить в окремій папці й має своє посилання:

    https://<нік>.github.io/<репозиторій>/<папка-проєкту>/

## Посилання

- Для клієнта й команди: `.../<папка-проєкту>/`. Тут видно лише Гант і завантаження команди, без бюджету й редагування.
- Для PM: `.../<папка-проєкту>/?edit`. Тут є оцінка, команда, параметри й бюджет.

## Як оновити план

1. Відкрийте посилання з `?edit` і внесіть зміни.
2. Натисніть «Завантажити data.json».
3. На GitHub відкрийте папку проєкту, натисніть **Add file → Upload files**, перетягніть файл і натисніть **Commit changes**.
4. Приблизно за хвилину посилання покаже новий план.

## Як додати новий проєкт

Скопіюйте папку `vendor-registration` під новою назвою (латиницею, без пробілів) і замініть у ній `data.json`. Або попросіть Claude зробити це за вас.

Файли `app.js` і `style.css` спільні для всіх проєктів.

## English version

Для англомовного плану підключіть у `index.html` папки проєкту `../app-en.js` замість `../app.js` (див. `carat-gallery/`). Після змін в `app.js` оновіть і `app-en.js`.
